# 🎄 WW New Year Event Platform

Веб-платформа для проведения новогоднего внутриигрового ивента и киберспортивной премии **WWAwards** для локального Discord-сообщества (~30 участников).

Проект представляет собой MVP-платформу, объединяющую управление турниром по Dota 2, скрытое голосование за номинации и праздничную викторину.

---

## 🛠 Технологический стек

- **Frontend:** React (Vite), JavaScript, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL / MongoDB
- **Authentication:** Discord OAuth2 (Вход на сайт в один клик через Discord-аккаунт)

---

## 🚀 Функционал платформы

### 1. Главная страница (Dashboard)
- Авторизация через Discord API. Автоматически подтягивает никнейм и аватарку пользователя.
- Таймер обратного отсчета до старта праздничного вечера.
- Интерактивный таймлайн с расписанием этапов ивента.

### 2. Новогодний Кубок (Турнирная сетка)
- Интерактивная турнирная сетка (Bracket) на 4–6 команд (микс сильных и слабых игроков, собранных через драфт).
- Карточки команд с отображением состава и позиций игроков.
- Панель администратора для ручного обновления результатов матчей в реальном времени.

### 3. WWAwards (Голосование)
- Интерактивные карточки для скрытого голосования за шуточные номинации (*«Фидер года»*, *«CEO Рошпита»*, *«Агент 007»*).
- Система защиты от накрутки: 1 уникальный `discord_id` = 1 голос в каждой номинации.
- Полная анонимность: результаты скрыты от пользователей и доступны только админу для торжественного объявления в голосовом канале.

### 4. Новогодний Квиз (Викторина)
- Одиночный тест на время (20 тематических вопросов по Dota 2 и внутренним мемам сервера).
- Валидация времени прохождения на бэкенде для защиты от спидранов со шпаргалками.
- Автоматическое формирование таблицы лидеров по баллам и времени.

## 📦 Порядок локального развертывания

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd ww-newyear-event
```

### 2. Настройка Бэкенда
1. Перейдите в папку бэкенда: `cd backend`
2. Установите зависимости: `npm install`
3. Создайте файл `.env` на основе `.env.example` и заполните данные:
   - Данные подключения к БД
   - Discord Client ID, Secret и Redirect URI (из Discord Developer Portal)
4. Запустите сервер: `npm run dev` (или `node src/server.js`)

### 3. Настройка Фронтенда
1. Перейдите в папку фронтенда: `cd ../frontend`
2. Установите зависимости: `npm install`
3. Создайте файл `.env` на основе `.env.example` (укажите URL бэкенда).
4. Запустите локальный сервер разработки: `npm run dev`

---

## 🔒 Безопасность и Ограничения (MVP)
- Изменение голосов в номинациях после отправки заблокировано.
- Обычные пользователи не имеют доступа к эндпоинтам результатов голосования и админ-панели сетки (проверка по ID администратора на бэкенде).
